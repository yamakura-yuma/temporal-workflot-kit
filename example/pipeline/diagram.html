補償は、そのステップ自身の出力を見られません。 登録されるのが実行より 前だからです。代わりに forward と同じ入力を受け取るので、前段までの出力は 手元にあります。自分のステップの出力が要る場合は、冪等キーで引いてください。 
chg, _ := saga.Step(ctx, s, "charge", a.Charge, a.Refund,
    ChargeReq{Order: in, Reservation: res})   // ← 前段の出力

// Refund は同じ ChargeReq を受け取るので、req.Reservation が使える
func (a *Activities) Refund(ctx context.Context, req ChargeReq) error {
    a.ledger.record("charge", req.Reservation)
    ...
}
## 前段の ID が、次段の補償にも渡っている * 連鎖する注文 "chain" を "ship" で失敗させる * saga は "no carrier available" で失敗する * ステップ "reserve, charge, ship, ship:undo, charge:undo, reserve:undo" が実行された * 補償 "charge" が受け取った前段の ID は "res-chain" * 補償 "ship" が受け取った前段の ID は "chg-res-chain"
